# Consumindo API

## 🚀 Sobre o Projeto

O **Consumindo API** é um projeto desenvolvido com o objetivo de demonstrar e praticar o consumo de APIs utilizando o framework **Spring Boot**. A aplicação permite a pesquisa de preços de veículos como carros, motos e caminhões, interagindo com a API por meio do console da IDE.

## 🎯 Objetivo

Aplicar os conhecimentos adquiridos no desenvolvimento de aplicações backend com Spring Boot, consumindo APIs externas para obter e processar dados, e apresentá-los ao usuário de forma eficiente.

## 🧪 Tecnologias Utilizadas

- **Java 17**
- **Spring Boot 3.3.3**
- **Maven**

## 📁 Estrutura do Projeto

- `src/main/java/com/example/consumindoapi`: Contém os pacotes e classes principais da aplicação.
- `src/main/resources`: Contém arquivos de configuração e recursos estáticos.
- `pom.xml`: Arquivo de configuração do Maven.

## 📚 O que foi aprendido

- Consumo de APIs externas utilizando Spring Boot.
- Processamento e apresentação de dados obtidos de APIs.
- Boas práticas no desenvolvimento de aplicações backend com Spring Boot.

## 📌 Observações

Este projeto foi desenvolvido com fins educacionais, visando aprimorar habilidades no consumo de APIs com Spring Boot.
